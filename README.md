# Socratic Learning Tool implementation

## Overview
This project is created to showcase a basic implementation of Socratic learning. Socratic learning suggested by the great philosopher "Socrates", suggests a unique way of learning. It is a form of active learning that uses a dialogue of questioning to explore underlying beliefs, assumptions, and ideas.

My motivation to create this tool was to test how good this socratic learning method is for other people. So this implementation involves teaching a few Data structure and algorithm problems using Socratic Learning.

This tool uses a LLM api call in the backend with a custom socratic learning prompt.

Features:
- User interface for exchanging dialogues.
- Code Executor
- Visualization
- Code performance analyzer


## Technologies Used
Python, Streamlit(for interface),Matplotlib
